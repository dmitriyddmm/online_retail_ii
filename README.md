# Online Retail II: удержание клиентов и RFM-анализ
## Бизнес-запрос
На основе данных о покупках определить, где искать возможности для повышения удержания клиентов.
## Датасет
Исходный файл на двух листах содержит информацию о покупках в онлайн в магазине с 01.12.2009 по 09.12.2011, всего 1.067.371 строка:
https://archive.ics.uci.edu/dataset/502/online+retail+ii
## Выводы
*	Выручка от продаж (после очистка датасета): 20.972.594,57.
*	Всего 5878 клиентов, из них 72,39% совершали повторную покупку.
*	Большая часть выручки (85%) получена в Великобритании, поэтому выводы наиболее пригодны для рынка Великобритании.
*	Наибольшая выручка ежегодно достигается в ноябре. Для определения наличия/отсутствия сезонности требуется дополнительный анализ.
*	Рассчитано медианное удержание на следующий месяц (20,5%). При исследовании поведения различных когорт их удержание следует сравнивать с ним.
*	Покупатели разделены на RFM-сегменты. Требуется дополнительный анализ отдельных сегментов с использованием большего числа признаков для установления причины ухода одних покупателей и продолжения активности других.
## Рекомендации
*	Установить, почему для некоторых продаж не указываются идентификаторы клиентов.
*	Провести анализ на наличие/отсутствие сезонности во временном ряде ежемесячной выручки.
*	Провести анализ причин полученного разделения покупателей на RFM-сегменты с использованием дополнительных данных для их более точного понимания: наличие/отсутствие акций и скидок, категории купленных товаров, способы привлечения клиентов (переход по рекламному объявлению и т. д.), технические неполадки сервиса, внутренние изменения сервиса (новые функции, изменение системы рекомендации товаров).
*	Ежемесячно рассчитывать удержание новых когорт и сравнивать показатели на одинаковом периоде времени (1, 3, 6 месяцев), отслеживать изменение удержания после бизнес-изменений.
## Файлы
*	Папка csv: CSV-файлы с промежуточными результатами анализа, используемыми для построения дашборда.
*	Папка dashboard: файл Power BI с дашбордом.
*	Папка images: изображения с диаграммами дашборда, используемые в отчёте.
*	Папка python: файл с кодом Python, проводящим анализ: загрузка данных из датасета, очистка данных, расчёт метрик, когортный анализ, RFM-сегментация, создание CSV-файлов.
*	Папка sql: файлы с PostgreSQL-запросами с промежуточными результатами анализа.
*	Файл report.pdf: отчёт о проведении анализа.
